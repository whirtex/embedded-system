## Atividades práticas - Mosquitto e MQTT

- [ ] Verificar se o Mosquitto e os clientes `mosquitto_sub` e `mosquitto_pub` estão instalados.
- [ ] Iniciar o broker Mosquitto localmente.
- [ ] Em um terminal, inscrever-se no tópico local `ibmec/test`.
- [ ] Em outro terminal, publicar uma mensagem no mesmo tópico.
- [ ] Confirmar o recebimento e registrar comandos e resultado.
- [ ] Repetir o teste com o broker remoto `test.mosquitto.org`.
- [ ] Inscrever-se no tópico remoto `iotbr/esp32`.
- [ ] Publicar uma mensagem no mesmo tópico e confirmar o recebimento.
- [ ] Confirmar com a professora se o tópico local será `ibmec/test` ou `iotbr/esp32`.

### Comandos sugeridos

```bash
mosquitto_sub -h localhost -t ibmec/test
mosquitto_pub -h localhost -t ibmec/test -m "Hello there!"
```

```bash
mosquitto_sub -h test.mosquitto.org -t iotbr/esp32
mosquitto_pub -h test.mosquitto.org -t iotbr/esp32 -m "Hello there!"
```
